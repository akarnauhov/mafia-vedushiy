ПУЛЬТ КООРДИНАТОРА «МАФИЯ» (живой квест)
=========================================

Это НЕ онлайн-игра.
Игроки расходятся по комнатам вживую. Программа — только тебе:
не сбиться, кто ещё в игре, что было ночью, кого выгнали.

Запуск на Windows
-----------------
Запуск_Windows.bat  или  двойной клик по MafiaHost.html
Интернет и установка не нужны. Можно с флешки.

Как вести вечер
---------------
1. Внеси ЗАНЯТЫЕ комнаты (пустые номера пропускай).
2. Игроки играют ночь на этаже.
3. Узнал итог → отметь мафия/доктор/комиссар → «Посчитать ночь».
4. Общий сбор и голосование вживую → «Отметить выбытие».
5. «Закрыть ночь → следующая».
6. Перерыв → «Сохранить» (скачается файл). Потом «Загрузить».

На экране сразу табло комнат: в игре / вне игры.
